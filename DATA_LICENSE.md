# Dataset License and Attribution

The TSSMRBench dataset is built from the public GitHub release notes of 300
open-source repositories. For each scenario we redistribute:

1. The **original release-note text** (`raw_text`), preserved verbatim for
   audit and provenance; and
2. an **LLM-rewritten normalized memory unit** (`memory_unit_text`) derived
   from that release note, used as the retrieval surface.

## Upstream ownership

Release notes are authored by and copyrighted to their repository owners and are
governed by each repository's own license (MIT, Apache-2.0, BSD, MPL, and
others; some repositories have no license file). TSSMRBench does not claim any
rights over the upstream release-note text. Each scenario record preserves the
repository identifier, the source URL, and release tag so that downstream users
can attribute the data and respect the terms of every upstream repository.

## Use and redistribution

- The dataset is released for **academic research use with attribution** to
  TSSMRBench and to the upstream repositories.
- Before any **commercial redistribution**, filter out repositories whose
  licenses do not permit redistribution of derived text, or whose `LICENSE`
  requires terms this release does not satisfy. The per-repo license should be
  obtained from the upstream repository (the source URL is recorded per node).
- If you publish results derived from this dataset, please cite TSSMRBench and
  acknowledge that the underlying content originates from the listed
  repositories.

## Generated content

The normalized memory units, questions, options, gold-support annotations, and
evaluation code are generated by the TSSMRBench authors (using LLM assistance as
described in the paper) and are released under the MIT license in the
repository's [LICENSE](LICENSE) for the software-generated portions, subject to
the upstream-content restrictions above.
